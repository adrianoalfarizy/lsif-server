# SAIF v0.26A.1.31.3 — Owned Vehicle Yellow Spawn Map Marker

Hotfix runtime-only. Saat `/myveh [nomor]` berhasil memanggil owned vehicle, server memasang marker kotak kuning global pada lokasi spawn. Marker hilang saat player mendekat dalam 18 meter, masuk ke kendaraan, kendaraan di-despawn/disimpan/dijual/hancur, atau player disconnect.

Tidak ada perubahan SQL atau database.
